# হিসাবপাতি — Android অ্যাপ (এলার্মসহ)

## ধাপ ১: আজানের সাউন্ড
`sound-here/azan.mp3` নামে আপনার আজানের ফাইল রাখুন (ছোট রাখুন, ৩০–৬০ সেকেন্ড)।

## ধাপ ২: GitHub-এ আপলোড
এই পুরো ফোল্ডারের ভেতরের সবকিছু (`.github` ফোল্ডারসহ) আপনার GitHub রিপোতে পুশ করুন।
পুরোনো `index.html` সরিয়ে দিন — নতুনটা `www/index.html` এ আছে।

## ধাপ ৩: APK নামানো
রিপোর **Actions** ট্যাবে যান → **Build Android APK** → সর্বশেষ রান → নিচে **Artifacts** থেকে `hisabpati-apk` নামান।
জিপ খুললে `app-debug.apk` পাবেন। ফোনে ইনস্টল করুন ("অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হবে)।

## ধাপ ৪: ফোনে সেটিংস (জরুরি)
- অ্যাপ খুলে নামাজ ট্যাবে "নামাজের এলার্ম চালু করুন" চাপুন, নোটিফিকেশন ও "Alarms & reminders" অনুমতি দিন।
- ফোন সেটিংস → অ্যাপ → হিসাবপাতি → Battery → **Unrestricted / No restrictions**
- Xiaomi/Oppo/Vivo/Realme হলে **Autostart** চালু করুন।
- ফোন সাইলেন্ট/ডিএনডি মোডে থাকলে শব্দ নাও বাজতে পারে।

## অ্যাপ আপডেট
`www/index.html` বদলে পুশ করলেই নতুন APK তৈরি হবে। Firebase ডাটা আগের মতোই থাকবে।
